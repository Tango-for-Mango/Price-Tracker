# Price-Tracker
System do asynchronicznego monitorowania i analizy historii cen produktów w serwisach e-commerce

Celem projektu jest stworzenie aplikacji webowej pozwalającej użytkownikom na śledzenie cen wybranych produktów w sklepach internetowych (wersja MVP: X-Kom oraz Helion). Zamiast ręcznie sprawdzać oferty, użytkownik dodaje link do interesującego go przedmiotu. System działający w tle regularnie pobiera aktualne dane cenowe, zapisuje je w bazie danych i wizualizuje historię zmian na wykresach, co pozwala na świadome podejmowanie decyzji zakupowych i unikanie fałszywych promocji.

Instrukcja użytkowania oprogramowania:
1. Zaloguj się lub utwórz konto na stronie
2. Znajdź interesujący cię produkt w sklepach Helion/X-KOM.
3. Skopiuj jego link
4. Wklej link w wyznaczone do tego pole
5. GOTOWE! Aktywny program sam automatycznie będzie pobierał i aktualizował cenę wyznaczonego produktu oraz obrazował ją na wykresie dla łatwej analizy. Dodatkowo wysyłane będą maile w przypadku spadku ceny produktu.
